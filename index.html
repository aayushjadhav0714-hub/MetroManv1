🧠 MetroMan Innovation Lab

From Route Planner to Mobility Decision Platform. This prototype adds personalization, predictive crowd intelligence, door-to-door planning, student mode and disruption response on top of the existing MetroMan experience.

🧠 Smart Mobility Decision Engine

Instead of showing only one route, MetroMan compares choices using time, fare, walking and crowd preference.

👥 Predictive Crowd Intelligence

Prototype forecast based on station characteristics and selected travel time. Clearly marked as estimated, not live data.

🚉 Door-to-Door Mobility

One journey view: first mile → Metro → last mile. This changes the product from a Metro-only planner into a complete mobility companion.

🎓 Student Mobility Mode

A segment-specific experience focused on affordability and travel behaviour.

🧬 Personal Mobility DNA

A prototype profile showing how MetroMan can learn user preferences over time.

🛟 Smart Disruption Response

When a disruption occurs, MetroMan can guide the user toward an alternate station, route or last-mile option.

MBA Innovation Proposition: The innovation is not another route map. It is personalized decision-making + predictive insight + multimodal planning + segment-specific value. Crowd and disruption data in this prototype are simulated; production deployment would require verified official/live data.
